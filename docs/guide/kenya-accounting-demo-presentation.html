Do not say “standalone accounting product”. Say integrated ledger with API.

Part B · How to integrate

Implementation checklist

  1. Create integration user (kind=integration)
  2. POST /api/v1/tokens — store Bearer token
  3. Send X-Tenant: nonlife on every call
  4. POST /api/v1/events/preview — fix rule/dimension errors
  5. POST /api/v1/events?sync=1 — same idempotency key
  6. Reconcile with trial balance + reports
