# Regulatory

## What this screen is for
The Regulatory dashboard shows the solvency snapshot, this quarter's returns and the latest technical provisions run. Regulatory returns are the forms filed with IDRA for a quarter or year: generate them, preview each form, download the set as XLSX or PDF, mark them reviewed and record the filing.

## What happens in the accounting
Returns and the solvency snapshot only read the ledger, so they post nothing. The technical provisions run calculates unearned premium and IBNR per class; when it is approved it posts the new IBNR provision and releases the prior quarter's.
