# প্রতিটি জার্নাল লাইনের মানে

প্রতিটি অ্যাকাউন্ট রোলের জন্য একটি সহজ লাইন, *View accounting* এ এবং টাকা নড়ার আগের নিশ্চিতকরণে প্রতিটি লাইনের নিচে দেখানো হয়। প্রথম কলাম
অ্যাকাউন্ট রোল (অনুবাদ করবেন না); বাকিগুলো বলে ওই অ্যাকাউন্টে ডেবিট বা ক্রেডিটের মানে কী।

| Role | Debit | Credit |
|---|---|---|
| bank_main | ব্যাংকে টাকা এসেছে | ব্যাংক থেকে টাকা গেছে |
| bank_clearing | পেমেন্ট গেটওয়ের মাধ্যমে টাকা ব্যাংকে আসার পথে | ক্লিয়ারিং থেকে টাকা ব্যাংকে গেছে |
| cheques_in_clearing | চেক পাওয়া গেছে, ব্যাংক এখনো টাকা জমা করেনি | চেক ক্লিয়ার হয়েছে বা ফেরত এসেছে |
| bank_charges | ব্যাংক চার্জ কেটেছে | ব্যাংক চার্জ কমেছে |
| suspense_receipts | সাসপেন্সের টাকা পলিসির সাথে মেলানো হয়েছে | এমন টাকা এসেছে যা এখনো কোনো পলিসির সাথে মেলেনি |
| premium_receivable | গ্রাহক আমাদের প্রিমিয়াম দেবেন | গ্রাহক টাকা দিয়েছেন, তাই পাওনা কমেছে |
| unearned_premium | কভারেজ দেওয়া হয়েছে, তাই এই প্রিমিয়াম আর গ্রাহকের পাওনা নয় | কভারেজ এখনো দেওয়া হয়নি — সময় না যাওয়া পর্যন্ত দায় |
| premium_income | প্রিমিয়াম আয় কমেছে | সময় পার হওয়ায় প্রিমিয়াম অর্জিত হয়েছে |
| premium_tax_payable | সরকারকে এই VAT আর দিতে হবে না | সরকারের জন্য আদায় করা VAT |
| stamp_duty_payable | সরকারকে এই স্ট্যাম্প শুল্ক আর দিতে হবে না | পলিসির স্ট্যাম্প শুল্ক, সরকারকে দিতে হবে |
| customer_refund_payable | গ্রাহককে টাকা ফেরত দেওয়া হয়েছে | গ্রাহককে টাকা ফেরত দিতে হবে |
| agent_receivable | এজেন্টের কাছে গ্রাহকের নগদ টাকা, এখনো জমা হয়নি | এজেন্ট আদায়ের টাকা জমা দিয়েছেন |
| commission_expense | পলিসি বিক্রির কমিশন খরচ | কমিশন খরচ কমেছে |
| commission_payable | কমিশন পরিশোধ বা আদায় হয়েছে | এজেন্টকে কমিশন দিতে হবে |
| commission_withholding_payable | কেটে রাখা কর সরকারকে দেওয়া হয়েছে | কমিশন থেকে কেটে রাখা কর, সরকারের পাওনা |
| producer_advances | প্রোডিউসারকে অগ্রিম দেওয়া হয়েছে | প্রোডিউসারের কমিশন থেকে অগ্রিম আদায় |
| accounts_payable | পাওনা পরিশোধ হয়েছে | সরবরাহকারী বা প্রোডিউসারকে দিতে হবে |
| dac_asset | বিক্রির খরচ পরের মাসগুলোর জন্য রাখা হয়েছে | রাখা বিক্রির খরচ এই মাসে খরচ হয়েছে |
| claims_outstanding | রিজার্ভ রিলিজ বা পেয়েবলে সরানো হয়েছে | রিপোর্ট হওয়া ক্লেইমে যত টাকা দিতে হবে বলে আশা |
| claims_expense | ক্লেইমের খরচ | রিজার্ভ রিলিজ হওয়ায় ক্লেইম খরচ কমেছে |
| claims_payable | ক্লেইমের টাকা পরিশোধ হয়েছে | অনুমোদিত ক্লেইম, এখন পরিশোধ করতে হবে |
| claims_ibnr_expense | ঘটেছে কিন্তু এখনো জানানো হয়নি এমন ক্লেইমের আনুমানিক খরচ | গত প্রান্তিকের IBNR অনুমান রিলিজ হয়েছে |
| ibnr_provision | গত প্রান্তিকের IBNR অনুমান রিলিজ হয়েছে | ঘটেছে কিন্তু এখনো জানানো হয়নি এমন ক্ষতির জন্য প্রত্যাশিত ক্লেইম |
| claims_recovery_income | রিকভারি আয় কমেছে | স্যালভেজ বা তৃতীয় পক্ষ থেকে আদায় |
| recovery_receivable | যে রিকভারি পাওয়ার আশা করি | রিকভারির টাকা এসেছে |
| rounding_difference | রাউন্ডিংয়ের পার্থক্য | রাউন্ডিংয়ের পার্থক্য |
| fx_gain_loss | বিনিময় হারে ক্ষতি | বিনিময় হারে লাভ |
| salary_expense | বেতন খরচ | বেতন খরচ কমেছে |
| employer_pf_expense | নিয়োগকর্তার প্রভিডেন্ট ফান্ড খরচ | নিয়োগকর্তার প্রভিডেন্ট ফান্ড খরচ কমেছে |
| bonus_expense | উৎসব বোনাস খরচ | উৎসব বোনাস খরচ কমেছে |
| salary_payable | বেতন পরিশোধ হয়েছে | কর্মীদের বেতন দিতে হবে |
| employee_tax_payable | কর্মীর কর সরকারকে দেওয়া হয়েছে | বেতন থেকে কেটে রাখা কর, সরকারের পাওনা |
| pf_payable | প্রভিডেন্ট ফান্ডের টাকা জমা দেওয়া হয়েছে | প্রভিডেন্ট ফান্ডে দিতে হবে |
| retained_earnings | সংরক্ষিত আয় কমেছে | কোম্পানিতে রাখা মুনাফা, বা আগের জের |
| premium_written_off | গ্রাহকের বাকি প্রিমিয়াম, আদায়ের মতো নয় বলে অবলোপন করা হয়েছে | অবলোপন করা প্রিমিয়াম কমেছে |

## যখন কোনো ঘটনায় লাইনের অর্থ বদলায়

ঘটনার ধরন ও অ্যাকাউন্ট রোল আগে (অনুবাদ করবেন না); এই ক্যাপশন শুধু সেই ঘটনার জন্য ওপরের ক্যাপশনের বদলে দেখানো হয়।

| Event | Role | ডেবিট | ক্রেডিট |
|---|---|---|---|
| POLICY_CANCELLED | unearned_premium | যে কভারেজ দেওয়া হয়নি তার প্রিমিয়াম, বিল থেকে বাদ বা গ্রাহককে ফেরত | কভারেজ এখনো দেওয়া হয়নি — সময় না যাওয়া পর্যন্ত দায় |
